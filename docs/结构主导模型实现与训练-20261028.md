2026-10-28：第一版代码已实现；CPU 实际缓存训练、四组 GPU 冒烟、两阶段断点续训和最大样本压力检查通过。正式全量 pilot 尚未提交，冒烟输出不能用于亲和力性能判断。设计依据见《结构主导融合与差分迁移设计-20261028.md》。本次保留旧模型、旧训练器和旧实验结果。

## 实际实现

- `appi/structure_context_model.py`：554,183 个可训练参数（默认宽度128、上下文64、2层4头）。预训练编码器通过冻结缓存提供输入，不在这个参数数目内。
- PPIformer 原始每残基128维经训练集标准化后，独立保留到读出；结构适配器是另一路。第一版仅使用现有 type-0 缓存，没有声称已接入 type-1 向量或稠密分子表面。
- 读取 `esm2_complex40_v1/sequences/*.pt` 的完整链逐残基 memory。现有长链重叠窗口特征全部保留，不改为全链均值。结构节点与完整序列的对应关系由已审计 manifest 提供；对齐歧义的候选位置给予同样的对应关系偏置。
- 结构 query 检索 ESM memory，区分另一伙伴、同伙伴、同链和对应残基。上下文 C 只参与结构 attention 的 S–S、S–C、C–S 三项 logits，没有 C–C 项；结构更新的 value 来自结构状态。
- 原始 S0 和结构更新拼接后进入跨伙伴残基对读出。使用 Cα 距离≤16 Å 的固定邻域，对称 pair 特征、求和/100、均值、接触数和伙伴结构汇总。求和除数100是固定数值尺度，不是能量单位。全局伙伴读出保留无接触情况下的结构信息。
- 最终只有一个 pKd 评分器；ΔpKd 严格等于 `S(mutant)-S(WT)`。没有独立差分预测头，单个复合物推理不需要 WT 或实验标签。

这能约束信息通道，不能保证模型使用几何而非家族身份，也不能保证 binder 外推有收益。原始特征被保留不代表预测头一定给予它足够权重。

## 训练、动态权重和选模

`train_structure_context.py` 支持 `--mode structure|fusion` 和 `--supervision absolute|transfer|shuffled`。

- 迁移阶段A：关闭 ESM，仅训练原始实验 ΔpKd，更新共享结构适配器、交互层和评分头。记录验证差分和零变化基线；绝对截距此时不可识别。
- 阶段B：绝对 pKd 与差分目标分别累积完整有效 batch 的梯度，然后用 GradNorm 动态权重合成，最后只执行一次模型 optimizer update。不保留固定 `lambda_diff=0.3`，也不叠加排序损失或 PCGrad。
- GradNorm 使用末层结构 qkv 和 contact-node 投影作为共享参考参数；记录两任务原始梯度、有效梯度和余弦。任务权重保持正值、和为2，以初始任务损失归一化学习速度。默认 alpha=1.5、控制器学习率0.01；这仍有超参数，不能宣传为没有任务取舍。
- 原差分损失系数0.3已移除。ESM 条件 dropout 概率另设为0.3，每个模型 optimizer update 采样一次，两任务及所有 WT/mutant 微批次共用，结构通道始终存在。排序死区独立设为0.3 pKd，含义也不同于损失权重。
- 训练损失为按来源/PDB平衡的、共同训练目标标准差缩放的 MSE；**训练损失与选模指标是不同概念**。
- 主 checkpoint：验证实验组等权宏平均排序最高（默认差异死区0.3 pKd），平局按差分 MAE 最小。次 checkpoint：绝对验证 MAE 最小。绝对 RMSE、Pearson、Spearman 仍报告，均不替代主选模规则。测试和外部16不用于选模。
- 每个阶段分别有 `last.pt`、`best.pt`、`best_absolute.pt`；阶段B从阶段A主 checkpoint 权重开始，用新 optimizer。续训保留模型、两个 optimizer、GradNorm 初始损失/权重和 CPU/CUDA RNG。
- `shuffled` 仅置换训练辅助差分标签，限制在相同WT/文献/方法/温度/WT测量的实验组内；绝对标签、验证和测试标签不变。源行映射与实际改变数写入 config；单例组无法置换。该对照引入任务冲突，不能单独充当有效迁移的证据。

## 正式 pilot 预算

`train_structure_context.sbatch` 为4组数组任务，同时最多运行2组，默认 seed42：

|组别|阶段A|阶段B|总 optimizer 更新上限|
|---|---|---|---:|
|structure_transfer|30 epoch 结构差分|100 epoch 结构绝对+差分|9,100|
|fusion_absolute|无差分预热|130 epoch 融合绝对|9,100|
|fusion_transfer|30 epoch 结构差分|100 epoch 融合绝对+差分|9,100|
|fusion_shuffled|30 epoch 置换差分|100 epoch 融合绝对+置换差分|9,100|

正式脚本用固定 epoch 预算，不提前停止；每 epoch 每个启用任务抽取4471条，完整打乱遍历加前缀，batch64对应70次更新。所有组的更新次数相同，但绝对组有更多绝对任务曝光，联合组每次更新处理两个任务，因此任务曝光和算力不相等，报告不得称为完全等算力对照。阶段A回滚到验证最优权重也属于预热策略的一部分。

命令行训练器自身仍支持早停（默认 warmup patience10、joint patience20）；正式 pilot 脚本显式覆盖为阶段总epoch数，实现上述固定预算。原先 ESM-B 作为历史序列参考，其旧 RMSE 选模和预算与新实验不同，不能直接解释为单一架构因素的因果比较。要确认泛化，应扩展独立seed、几何消融和独立未见体系。
