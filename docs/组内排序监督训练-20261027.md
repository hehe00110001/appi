# 组内排序监督训练（2026-10-27）

目的：检验在现有残基交互模型及来源/PDB均衡目标上，添加同实验背景的组等权排序监督，能否改善未见体系的变体排序。用户已授权实施和提交训练。本轮只改监督，不加入可加读出、adapter或外部ΔΔG预测器。

## 实验设计

固定40%划分 `joint_training_complex40_v1`，缓存 `residue_cache_complex40_v1.pt`。绝对训练4471条，配对训练3061条。保留现有width128/layers2/heads4残基交互模型，共391518个可训练参数；ΔpKd始终为同一评分器的S(mut)-S(wt)。

|组别|目标|seed|
|---|---|---|
|B|来源/PDB均衡绝对MSE|42、43、44|
|C|B + 0.3 × PDB均衡差分MSE|42、43、44|
|R|C + 0.1 × 实验组等权排序hinge|42、43、44|

绝对与差分MSE按共同训练标签标准差的平方缩放；排序hinge按该标准差缩放。0.1是预先固定的初步权重，不声称最佳。数值损失延用已有均衡目标，无额外端点绝对损失。

同seed三组使用相同归一化、初始化和绝对记录顺序，C/R使用相同差分记录顺序。归一化仍采用非SKEMPI绝对训练子集，与上一轮A/B/C保持一致。每轮4471条绝对记录、70次更新，活跃绝对/配对数据全部访问。排序增加前后向计算，所以优化器更新数相同但FLOPs不相同。

AdamW lr=0.001、weight_decay=0.0001，梯度裁剪5；有效batch64、microbatch8、attention_limit=1e6；最多200轮、patience25。统一按完整绝对验证RMSE选模，保留与已有基线的可比性；同时记录验证组内排序指标，但不按测试或排序结果更换checkpoint。这主要检验保留绝对预测选模目标时的增益，不等同于独立优化排序上限。

## 排序组与采样

组键：WT特征路径（绑定链界面和固定几何）＋Reference＋Method＋原始Temperature字段＋WT pKd（12位有效数字）。缺失关键元数据的记录隔离为单独组。温度原始字段保留assumed与实际报告的区别。相同组内同一突变图的重复记录取平均mutant pKd；本批数据没有实际合并的重复变体。WT测量值用于保守区分实验参考，不依据突变效果决定分组。

这不能保证未记录的pH、缓冲液或所有测量条件完全相同；来源文献与方法字段是当前数据支持的保守近似。WT数值略有差异也可能将同实验拆开，宁可减少比较也不强行合并。

只比较标签差严格大于0.3 pKd的变体，margin=0.25 pKd。二者为预设实验参数，不宣称0.3就是实测噪声范围。每次更新抽4个组，每组均匀有放回抽4个有效比较。每轮先打乱遍历全部有效组，再取下一次打乱前缀：280次组呈现、1120次比较呈现。所有201个有效训练组每轮至少访问一次。

同一组抽相同比较数，先组内平均与对组平均等价；组权重不随组大小或可生成比较数量增长。这里等权单位是实验组，不保证每个PDB/同源组的排序总权重相同；日志和清单保留两者映射。比较两端保持在同一梯度计算中，按完整比较拆微批次，梯度累积保持采样目标不变。

## 评估

每轮保存训练分项损失、数据覆盖、有效组覆盖和比较数，验证绝对/差分指标及实验组等权排序。最终保存逐条val/test预测和checkpoint。

自动汇总核验输入/代码哈希、同seed初始化/归一化、绝对权重、C/R差分清单、每轮全覆盖、选模epoch及预测重算指标。输出总体绝对/差分误差、PDB/同源组内指标、实验组等权排序正确率/Spearman、移除最大组敏感性检查。

排序预测平局记半分，不把常数预测组从正确率分母排除；Spearman对常数预测未定义，单独报告有效组数。三seed共用测试集，先对每个实验组求seed平均差，再按40%同源组做2000次配对bootstrap。测试有效排序组仅覆盖8个同源组，置信区间只能作为有限数据的描述；此前测试集已被查看，不称为新盲测。
