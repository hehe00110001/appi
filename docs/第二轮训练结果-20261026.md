# 第二轮训练结果与耗时核查（2026-10-26）

Slurm 数组 15763_0–11 全部 COMPLETED，退出码均为 0:0。12 个正式运行均 limit=0，
smoke_test=False，使用固定新划分和公共配对端点绝对监督（pair_absolute_weight=1）。
训练输入为 4461 条绝对记录及 3063 条配对，验证 397/268，测试 401/270。
输入 CSV、训练代码和模型代码哈希均与运行配置一致；预测 ID 与目标逐条核对通过。

**为什么耗时短**

- 每任务实际墙钟时间为 1 分 16 秒至 3 分 38 秒，累计 CPU 时间为 25.36–27.40 秒，申请 2 CPU 核。
- 配置 device=cpu，没有使用 GPU；Slurm 节点名 gpu16 不表示该任务使用了 GPU。
- PPIformer 编码器未进入本轮训练图。读取 5248 个缓存文件中的 768 维 pooled 向量，
  仅训练 LayerNorm → Linear(768,256) → GELU → Linear(256,1) 预测头。
- 可训练参数精确为 198657（约 20 万）。每轮绝对记录遍历一次，共 ceil(4461/64)=70 个 batch，
  每步同时抽等大小的配对 batch，用于公共端点绝对项及 joint 模式的差分项。
- 实际运行 30 或 32 轮，每个可训练参数的 Adam step 计数经 checkpoint 确认为 2100 或 2240。
  不是空循环、只跑几条样本或执行到读缓存就退出。
- 最佳 epoch 为 5 或 7；之后连续 25 轮绝对验证 RMSE 未改善，按 patience=25 正常早停。
  配置中的 200 是最大轮数，不是要求每次都跑满。

按文件修改时间估算，写 config.json 后到生成 metrics.json 只有 9.04–9.76 秒；
首轮到末轮 epoch JSON 的时间间隔为 8.71–9.42 秒，平均每轮约 0.3 秒。
config 在读取特征、创建模型和优化器之后才写出，因此作业的大部分墙钟时间发生于正式迭代之前。
这个阶段包含环境导入、缓存读取、张量构造和初始化。没有逐段计时，不能精确分配各阶段耗时；
后续任务更快与缓存预热相容，但未做实验证实，不能把全部差异直接归因于文件系统缓存。
文件修改时间是近似运行证据，不是训练计算的专用计时器。

**结果**

均值±三个 seed 的样本标准差；这不是样本泛化置信区间。绝对单位 pKd，差分单位 ΔpKd。
全部运行按预定的绝对验证 RMSE 选最佳 epoch，没有按测试集挑 seed 或 lambda。

| 配置 | 绝对 val RMSE | 绝对 test RMSE | 差分 val RMSE | 差分 test RMSE |
|---|---:|---:|---:|---:|
| absolute | 1.597±0.013 | 2.341±0.200 | 1.897±0.010 | 2.063±0.014 |
| joint λ=0.05 | 1.595±0.015 | 2.323±0.242 | 1.879±0.023 | 2.058±0.022 |
| joint λ=0.1 | 1.591±0.015 | 2.335±0.247 | 1.874±0.024 | 2.057±0.024 |
| joint λ=0.3 | 1.587±0.022 | 2.434±0.244 | 1.866±0.024 | 2.054±0.027 |

| 配置 | 绝对 test Pearson | 差分 test Pearson | 差分 test 按组等权 MAE |
|---|---:|---:|---:|
| absolute | 0.669±0.015 | 0.373±0.016 | 0.981 |
| joint λ=0.05 | 0.676±0.025 | 0.377±0.028 | 0.987 |
| joint λ=0.1 | 0.674±0.031 | 0.376±0.030 | 0.996 |
| joint λ=0.3 | 0.662±0.038 | 0.372±0.031 | 1.018 |

若只按预先约定的平均绝对验证 RMSE 排序，λ=0.3 最低；但它的绝对测试 RMSE 比基线高约 4.0%。
λ=0.05 在测试表中绝对误差较低，不应据此事后选定它。
差分测试 RMSE 从 2.0625 到 2.0541 只改善约 0.41%；按组等权 MAE 没有同步改善。
当前证据不支持宣称联合监督带来了明确、全面的收益，也不足以否定所有架构下的联合监督。

**常数基线、幅度与分布**

| 差分恒为 0 | 1.992 | 2.101 |

最后一项是标签先验的统计参照，不是满足所有 WT/mut 交换约束的共享评分模型。
模型差分预测的 RMSE 略好于零差分，但仍差于训练差分均值参考；差分学习还比较弱。
差分测试预测标准差约 0.401–0.469，标签标准差 1.793。各模型差分测试平均 bias 为 +1.18–1.19。
不能只看 Pearson 非零或幅度增长，就认定突变效应已学好。

来源比例已平衡，但绝对 train/val/test 标签均值仍为 7.612/8.581/8.874。
绝对测试平均 bias 为 -1.35 至 -1.50 pKd，有系统性低估。
测试集和公共绝对监督目标均与首轮不同，不能把首轮 1.644 与本轮 2.341 直接比较为同一基准上的退化。
差分 test 270 条只来自 15 个 PDB 组；样本相关性和组间差异仍需考虑。

**训练曲线说明**

absolute seed42 的训练绝对缩放 MSE 从 0.4849 降到 0.1371，公共端点 MSE 从 0.3610 降到 0.1222。
与此同时，绝对验证误差在第 7 轮达到最佳后总体上升，最后一轮为 1.8025。
其他配置也有类似趋势。这支持过拟合/跨组泛化受限，而不是简单的“训练时间不够”。
