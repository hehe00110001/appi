# 同源划分方法核实与 40% 对照

## 纠正此前的说明

当前使用的 `proteinea/ppb_affinity` 的 `filtered` 配置来自 *Beyond Simple Concatenation: Fairly Assessing PLM Architectures for Multi-Chain Protein-Protein Interactions Prediction*。该版本提供作者定义的同源划分。

- 数据卡：https://huggingface.co/datasets/proteinea/ppb_affinity
- 论文 §2.1.3：https://arxiv.org/html/2505.20036v1#S2.SS1.SSS3
- 官方实现：https://github.com/Proteinea/ppiseq/blob/f15f4a919e80d6945e84fd5570c5dda7561da322/data_processing/data_postprocessing.ipynb

首轮 `joint_training_v2` 保留作者原始 split，只应用已有结构资格筛查、外部链排除等规则。因此首轮继承作者按复合物拼接序列进行的 30% 划分；此前笼统说“首轮没有同源划分”不准确。它没有通过另行施加的任一单链 30% 隔离，并不等于没有采用作者的同源划分。

第二、三轮 `joint_training_resplit_v1` 则重新按 PDB/共享特征分组分配，未保持或重新验证作者的同源分组。二者必须区分。

## 为什么此前严格筛查大量减样本

此前自定义 BLAST 规则比较任一单链，要求一致性≥30%、覆盖较短链≥80%，然后在既有 split 上删除较低优先级的冲突记录；4473→709 指的是这套更严格筛查下的训练记录数。

作者的方法比较整个复合物拼接序列，以同源组移动记录，而非删除冲突训练记录。这两种方法的比较对象、覆盖要求和冲突处理均不同，不能把 709 条解释为复现作者方法必然得到的规模。

官方 notebook 的具体定义：去除 `Ligand Sequences` 中逗号，接着去除 `Receptor Sequences` 中逗号，二者直接相接，保留源链顺序；`MMseqs2 easy-cluster` 使用 `--min-seq-id 0.3 --cluster-mode 1 --single-step-clustering`，说明及默认参数为 `-c 0.8 --cov-mode 0`，要求 query 和 target 两边覆盖率都达到 80%。作者先将大簇放入训练集，再用 `easy-search` 发现并将跨集合相似记录连同其 PDB 移入训练集，最后分 validation/test；论文报告约 79%/12%/9%。

不存在覆盖所有 PPI 任务的一种唯一同源划分标准。例如 PPIformer 的 SKEMPI 评估按 `Hold_out_proteins` 分组，并检查界面结构相似性；不能将其直接称为普通 40% 单链切分。参考：https://arxiv.org/html/2310.18515v3#A3.SS1 。

## 本次采用的方法及与原实现的差别

采用上面已有明确出处的复合物拼接序列方法，将阈值按用户要求改成 **40%**，保持双方覆盖≥80%和连通分组。只处理已经合格的 5259 条绝对记录、3601 条配对，不重新过滤或平均标签。保留同 PDB、共享缓存、配对关联约束。

为满足尽量保留首轮划分和大致比例的要求，本次不照抄作者“先75%再往训练集扩张”的分配步骤：先按原 split 在每个完整组中的记录数确定归属，再用只依赖记录数、来源及组数的优化移动/交换完整组，目标85%/7.5%/7.5%，并给予保留原归属的小幅偏好。亲和力标签不参与选择。另对全部拼接序列做 MMseqs2 搜索，合并聚类遗漏的阈值内连接，核对最终跨集合命中数。

因此应称为“基于 PPiSeq 方法的 40% 复合物拼接序列划分”，不是原论文30%划分的逐字复现，也不保证任意单链间一致性都低于40%。同源组保留全部成员，不会只取代表序列训练。

## 训练对照

固定当前模型（128维、2层、4头、391518参数）、种子42、优化器、损失、训练上限、早停和选模规则。暂不引入组均衡损失，避免把划分与训练目标同时改变。

1. 首轮 split + 当前模型：absolute 与 joint λ=0.3，重新训练。
2. 本次40% split + 当前模型：absolute 与 joint λ=0.3，重新训练。
3. 当前 PDB split + 当前模型：复用 `runs/affinity_residue_v1` 已完成的同两组 seed42。

三个 split 的内部测试样本不同，不能把内部 Pearson 差异全部归因于模型优劣。共同外部16条使用固定用户标签作为横向对照；这些标签已经被查看，不应再用于选择超参数。各模型仍只按各自绝对验证 RMSE 选 checkpoint。

实现：`scripts/split_complex_homology40.py`、`scripts/rebind_residue_cache.py`、`scripts/prepare_split_comparison.sbatch`、`scripts/train_split_comparison.sbatch`。冻结残基特征数值完整复用，缓存转换逐条核对原记录、标签和特征路径，只更新 split 对应的审计元数据。
