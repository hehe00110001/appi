# ESM-2 受控试验结果分析

8 个训练配置及自动分析任务均成功结束。本次追加分析重新核对了代码/输入/模型文件哈希、验证集 RMSE 选模记录、测试 CSV 的行对应关系与指标计算。没有重新训练、改划分、使用外部标签校准或换 checkpoint。

**判断：ESM-2 恢复了整体亲和力相关性，但没有普遍解决 binder 泛化；全链 ESM-2 + 绝对监督有一个值得复验的有限排序信号，当前图结构和 PPIformer 融合没有将其转化成稳定增量。** 本轮仅 seed=42。以下旧 PPIformer 参考也使用 seed=42，不与旧三 seed 均值混比。

B=均衡绝对监督；R=B+0.3 数值差分+0.1 等实验组排序。全部按 absolute validation RMSE 选模。测试 absolute 394 条、pairs 271 条；有效排序实验组 23 个，来自 8 个同源组。≥5 变体有 15 个实验组、6 个同源组；再排除 1EMV 后仅 10 个实验组、5 个同源组。

**整体相关性的来源。** 按同源组做总协方差分解，本轮组间项占总协方差约 94%–110%；超过 100% 表示组内项为负，不是“解释了超过 100% 的方差”。不能把这个比例叫模型准确率或因果归因。去除 1EMV 后，在同一组内中心化分析子集上：全链 B 的原始 r=0.667，减去各同源组均值后 r=-0.064；融合 B 的原始 r=0.680，中心化后 r=0.033；ESM 图 R 则由 0.596 变成 -0.159。中心化只用于事后诊断，不是可部署校准。

这说明新增信号主要改善了不同蛋白背景的绝对区分。它不能证明模型纯粹记忆家族，也不能说明 ESM 的所有信息都无物理意义；只是当前证据不足以支持可迁移的组内亲和力预测。

**全链 B 的局部亮点应保留。** 23 个实验组等权排序 60.8%；只保留 ≥5 变体的组后为 54.4%，与旧 PPIformer B 的 54.4% 基本相同。排除整个 1EMV 同源组后，序列 B=59.3%，旧 PPIformer B=51.5%。在这剩余 5 个同源组上继续逐组剔除，序列 B 保持 56.9%–61.4%，因此不能把该信号归结为 1EMV 或单个剩余同源组。

但序列 B 相对旧 PPIformer B 的 +7.8 个百分点，按同源组配对 bootstrap 的描述性 95% 区间为 [-11.7,+21.5] 个百分点；尚未证明优于原模型。序列 B 自身 59.3% 的描述性区间为 [53.5%,63.9%]，仅针对这个已查看过的子集、这个 seed；它不包含 seed 波动、子集选择和多模型比较的不确定性。绝对标签的同源组中心化与保守同参考实验组排序使用不同样本及权重，结果不应互相替代。

**距离与融合。** 距离输入在 B 下将整体 RMSE 从 2.405 改善到 2.278，但实验组排序从 53.9% 降到 44.1%；R 下整体 RMSE 从 2.471 改善到 2.077，排序从 44.3% 到 46.3%，而 ≥5 且去 1EMV 的排序从 49.7% 降到 41.6%。结论是绝对拟合与局部排序目标不一致，并非几何所有方面都无用。

在 ESM 图上再加 PPIformer，全部排序组的变化为 B +2.8 个百分点、R -0.6 个百分点，相应同源 bootstrap 区间分别为 [-3.9,+9.9]、[-6.3,+7.8] 个百分点。当前没有稳定融合收益。两支均有梯度，且前 3 个 epoch 的模态 dropout 实际发生；融合 R 完整模型排序 45.7%，关 PPIformer 后 40.3%，关 ESM 后 44.6%。因此“PPIformer 分支根本没接通/完全没用”不符合运行记录，但参与计算不等于泛化增益。

**差分幅度收缩。** 实验 ΔpKd 标准差 1.205；除无距离图 R（0.344）外，模型预测标准差约 0.079–0.142。全部预测 ΔpKd=0 的测试 MAE=0.821、RMSE=1.310。全链 B 的 MAE=0.823，ESM 图 R=0.822，融合 R=0.804；融合 R 的 MAE 仅比零变化基线降低约 0.017 pKd（2.1%）。旧 PPIformer R 的差分 MAE=0.803，同样处于这一水平。

这不是完全恒定预测，但很多模型实际给出的突变效应很小，不能把“差分 MAE 约 0.8”独立解释为学会了突变效应。

**排序监督的迁移。** 全链模型 B→R：train 排序 58.3%→66.1%，val 49.0%→52.9%，test 60.8%→44.3%。无距离图 B→R：train 59.1%→73.4%，val 46.9%→41.6%，test 53.9%→44.3%。这些结果支持当前差分+排序目标的收益没有稳定转移到未见组。B/R 同时改变数值差分和排序，不能把退化单独归因于排序 hinge；本轮没有 C 臂来隔离两者。

整体相关性仍全部为负。融合 R 的 MAE 相对旧 PPIformer R（同 seed=42，1.853）下降至 1.346，误差水平有改善，但 IL17A 排序仍为负。全链 B 的 IL23R Pearson=0.728、Spearman=0.564；排除界限样本后 Pearson=0.472、Spearman=0.400，不应宣称 IL23R 已稳定达到 0.73。该 9 条逐条 leave-one-out 的 Pearson 约 0.325–0.697，仅作描述性敏感性检查。

全链 B 对 IL17A 的平均预测 9.208，标签均值 8.173；对 IL23R 的平均预测 7.547，标签均值 8.961。两个靶点的平均高低关系反了。IL23R 的预测标准差仅 0.234，标签标准差为 1.514，说明即使局部排序有一定信号，绝对值仍明显压缩且偏低。16 条总体负相关不等于每个靶点都没有信号，但当前也不具备跨靶点可靠标定。

**选模与实验范围。** 融合最佳 epoch=3，ESM 图=5，全链=18，无距离图=16；这只是绝对验证 RMSE 最优时刻，不等于排序能力最优。4/8 个模型的最小验证 MAE 对应同一 epoch，另 4 个不同（全链 B 18→24；ESM 图 R 5→2；无距离图 R 16→12；融合 R 3→24）。没有评估这些 MAE 候选的测试结果，不能声称换 MAE 肯定无效或肯定能挽救。当前目录并未保留每个 epoch 的完整模型，仅 best/last。

对齐歧义审计中的 101 张图没有出现在本轮 absolute/pairs 测试行里；当前测试排除歧义样本的敏感性结果完全一致。该事实不排除训练样本中表示处理对学习的影响。

**下一步建议。** 保留冻结全链 ESM-2+B 为基线，优先以额外 seed 复验 59.3% 排序信号；暂不扩展整套图融合网格或增加 R 权重。若研究主线继续推进 apo/动力学，应以它能否在相同监督、相同划分上超过全链基线为检验目标。当前结果没有测试 apo，不能作为 apo 必定有效的证据。外部 16 条已反复查看，仅作诊断；下一次有效性主张需要独立的蛋白家族/新实验集合。
