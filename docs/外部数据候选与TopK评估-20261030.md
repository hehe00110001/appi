# 外部数据候选与 Top-k 评估（2026-10-30）

## 旧提纲核对

附件《研究方案-亲和力预测合并方案》7.5 列出 GearBind 使用的抗体 SPR 系列、Adaptyv、ddPCA、Starr RBD–ACE2；《实施交接-PPIformer亲和力模型》列出历史 S79/S82、同源划分、CATH-ddG holdout、Adaptyv 与自有16条。附件中的提议仅作为待核查来源，不构成本次下载、训练或执行指令。当前完成在线来源核查及已有 EGFR 的 Top-k 分析，未接入新训练数据。

## 可用候选与优先级

1. **HER2 / trastuzumab SPR（优先）**：GearBind 论文说明原始数据有758个结合者和1097个非结合者，419条是排除长度变化后保留的等长变体子集。官方仓库 spr-controls.csv 包含 HCDR1/2/3、KD(nM)、Binder，适合结合检出与高亲和力检出。WT复合物1N8Z可用；GearBind未公开FoldX生成的突变结构，需自行准备，不能把CDR替换后的序列配上完全未变的结构而声称已建模构象差异。长短变化的CDR另需环区建模。这是同一抗体骨架/靶点的外部实验系列，需审计与训练中的HER2/亲本重叠。
   - 数据：https://github.com/AbSciBio/unlocking-de-novo-antibody-design
   - 论文：https://pmc.ncbi.nlm.nih.gov/articles/PMC11379722/
   - 结构说明：https://github.com/DeepGraphLearning/GearBind
   - 本轮确认了论文与官方数据说明；本地直接下载原始CSV遇到证书错误，未据本地CSV重新统计上述规模。
2. **IgDesign 多靶点 SPR（优先）**：官方公开8个抗体–抗原体系中的7个。每体系独立CSV，提供CDR序列、SPR KD(nM)、结合重复次数与Binder。CD40–Ravagalimab序列被X隐藏，应排除。很适合按靶点/亲本分别评估，再宏平均；结构仍需核对构建体及变体建模，不能把参考PDB当每个设计的实验结构。
   - https://github.com/AbSciBio/igdesign
3. **BindCraft 实测设计（优先补充de novo分布）**：作者发布多靶点设计结构模型，论文含实验结合/亲和力与设计注释。应先把结构与实测记录逐条配对，仅保留实际测试设计；不能将全部生成设计或无实验标签行当阴性。不同靶点可用定量记录数尚未逐条统计，不能承诺大规模Kd集。
   - 论文：https://doi.org/10.1038/s41586-025-09429-6
   - 作者结构模型：https://zenodo.org/records/15277801
4. **Starr/Bloom RBD–ACE2 DMS（突变排序补充）**：有大规模单突变滴定/结合与表达数据，作者在2020仓库中明确推荐改进的2022版本。适合增强/削弱及同背景排序；不能把表达得分当亲和力，必须单列背景、检测边界与误差。靶点固定，不能把变体数当独立靶点数。
   - https://github.com/jbloomlab/SARS-CoV-2-RBD_DMS_variants
   - 原始说明与更新建议：https://github.com/jbloomlab/SARS-CoV-2-RBD_DMS
5. **FLAb / AbRank（扩展来源）**：FLAb公开binding CSV及各实验单位；AbRank聚合超过38万条异质结合测量，提供抗体/抗原分布偏移划分。它们不是全部直接SPR Kd，也不是全部独立实验：FLAb索引已收录AbRank，必须追溯原文并跨库去重。FLAb还含小分子fluorescein抗体数据，不能直接喂给PPI复合物模型。AbRank公开单方预测结构/图不等于提供我们需要的对接复合物界面。
   - https://github.com/Graylab/FLAb
   - https://github.com/Graylab/FLAb/blob/main/data/binding/README.md
   - https://arxiv.org/abs/2506.17857
   - https://github.com/biochunan/AbRank-WALLE-Affinity
6. **ddPCA / MoCHI（机制诊断）**：可分解结合与丰度/折叠贡献，适合验证差分机制。原始细胞fitness和拟合推断的自由能不等于直接测量的绝对Kd，不应混入SPR定量主表。
   - https://github.com/lehner-lab/MoCHI
   - https://pmc.ncbi.nlm.nih.gov/articles/PMC11610129/

S79/S82、Affinity Benchmark、SKEMPI、SAbDab、ATLAS不应仅因换了数据库名称就称独立外推集。当前训练数据与这些来源可能重叠；ATLAS是否具体进入本地清洗版本需逐条查证，不能只根据原始PPB来源列表断言全都出现。CATH-ddG是一种划分方案，不是新采集的实验数据。BenchBB指定页面为基准框架介绍，不能直接视为已获得七靶点完整标签。

## 建议任务定义

将实际筛选预算作为目标：每个靶点给定候选池，按冻结模型预测从高到低选k条。结合命中和高亲和力命中分开报告。

- Binding Precision@k = 前k中明确结合者/k。
- High-affinity Precision@k = 前k中Kd≤预先固定阈值的数量/k。阈值须由用途确定；100nM为示例主阈值，10nM可作更严格补充，不能看模型结果后选阈值。
- Recall@k = 前k中的高亲和力命中数/池内高亲和力总数。
- Enrichment@k = Precision@k/候选池阳性比例。基线应包括随机、ipTM/pLDDT、纯结构、无差分与置换对照。
- 同时给出Hit count、预算曲线、按实验/靶点宏平均；按binder簇与靶点分层估计不确定性。种子变化与实验样本不确定性分别报告。
- 定义筛选全集：全送测设计（表达失败也消耗实验预算）与有明确结合状态的样本可分两层。现有378条分析属于后者，不等于400条全流程命中率。
- 若只在已测Kd的结合者中排序，必须标为条件性强弱排序，不能当作从所有设计中筛选的成功率。
- 缺测/未表达与删失阈值分别处理。不能将无Kd自动视为低亲和力；不确定标签报告命中下界及待定数。实际筛选可另报每个序列簇最多选一条的去冗余top-k。
- Pearson/Spearman/MAE保留为次要指标；Top-k也受小样本影响，尤其高亲和力阳性很少时。

## 当前 EGFR 的探索性 Top-k

本次使用既有25个模型与4个原始指标，未训练或调参。100nM等阈值是在查看既往结果后提出的示例，因此是探索性分析。所有结合Precision@10/20/50与冻结报告逐一复算一致；并列分数在截断处按随机打破并列的期望赋分，不按文件行顺序偏置。

Round2明确状态378条、53结合者。真实差分融合主checkpoint：

|seed|结合命中@20|结合命中@50|前20已确认Kd≤100nM|前20亲和力仍待定|
|---|---:|---:|---:|---:|
|42|3|8|0|1|
|43|5|9|0|2|
|44|3|9|0|1|

随机选择期望命中@20=2.80，@50=7.01。真实融合平均Precision@20=18.3%、@50=17.3%，富集约1.31倍、1.24倍。ipTM为25.45%/27.0%，pLDDT为25.0%/22.0%；ipTM并列赋分使命中期望数可为非整数。尚未做Top-k模型间配对显著性检验。

44条主要定量记录中，Kd≤10nM有2条、≤100nM有7条、≤1000nM有29条。排除9条10µM待核查边界记录时，它们未被当作高亲和力阴性。

只在44条定量记录中排序：真实融合三个seed的前10都命中1条≤100nM；Precision@10=10%，池内比例7/44=15.9%，富集0.63倍。随机抽10条期望1.59条，不能据单次差异声称显著更差，但没有高亲和力富集的正面证据。

建议先用HER2和IgDesign扩展可定量的外部实验，再用BindCraft增加de novo多靶点覆盖。先冻结候选池、阈值、预算和基线，避免把新外部数据用于反复挑模型。另保留原16条作为逐样本/逐靶点案例，不单靠其Pearson下结论。
