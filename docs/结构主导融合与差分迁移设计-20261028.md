# 结构主导的 ESM/PPIformer 融合与差分迁移设计

状态：第一版已实现并通过 CPU/GPU 工程验证，正式全量训练尚未提交；实现细节、预算和验证凭据见[结构主导模型实现与训练](结构主导模型实现与训练-20261028.md)。本方案响应用户要求：保护 PPIformer 信息，减少 ESM 独占预测路径，并明确让差分任务训练共享表示。它不是把当前实验更名为已完成的新机制，也不保证外推效果。

## 设计原则

原始结构表示应保留独立通道；序列模型提供上下文与注意力路由，第一版不直接提供最终打分捷径。差分与绝对任务使用同一个可单独预测复合物的函数。注意力负责信息聚合，动态多任务优化负责损失贡献，不能把二者混称。

当前工程已验证的限制包括：官方输出为每残基 type-0 128 维，编码器内部还有 type-1 64 路向量；现有缓存仅保留 type-0；ESM pilot 使用界面节点提前相加；R 仍为固定 0.3 差分和 0.1 排序；绝对验证 RMSE 选模可能与排序目标不一致。

## 编码与保留

1. PPIformer 的掩码预训练编码器冻结，输出原始结构标量 S0[N,128]。下游增加小型结构适配器，但 S0 作为独立输入始终保留，不能先与 ESM 相加后丢掉身份。
2. 另行扩展缓存以留存原生 type-1 输出和精确节点对应关系。第一版先在现有标量上隔离验证融合/监督路径；向量通道作为后续独立消融，不同时改变所有因素。
3. 使用向量时采用等变更新或旋转不变收缩，例如向量与残基间单位方向的点积、向量内积。不能直接将 xyz 分量展平拼到普通 MLP。冻结 type-0 并不等于它没有编码几何，也不能声称加向量一定提高信息质量。
4. ESM2-650M 保持冻结，完整链逐残基输出作为 memory，不再只保留界面位置。各模态独立标准化。结构宽度保持 128，序列条件通道可先设 64；这是容量控制起点，不是信息量比例或最优超参数结论。

## 结构位置查询序列，序列调制结构信息流

先由结构残基查询完整序列 memory：

`C_i = CrossAttention(Q=S_i, K=E_full, V=E_full)`

使用节点/序列位置映射，并区分本伙伴与另一伙伴的 memory。这里 ESM 编码仍逐链独立，伙伴交互在下游 attention 中发生。C_i 表示结构位置对应的全链序列上下文。

随后建立分解的残基注意力 logits：

`l_ij = (qS_i·kS_j + qS_i·kC_j + qC_i·kS_j)/sqrt(d) + b_geometry(i,j)`

`a_ij = softmax_j(l_ij)`

`U_i = sum_j a_ij Wv S_j`

其中三项分别对应结构—结构、结构—序列上下文、序列上下文—结构。各项独立投影和归一化，保留贡献日志；不靠原始 128/1280 维度决定谁更强。第一版不加入独立的序列—序列 logits 项。

关键约束：第二步的 value 来自结构通道；最终读出接收 S0 与结构更新 U，不直接接收 C 或全链 ESM pooled score。ESM 通过“让结构特征如何互相读取”参与模型，而不是另设一个纯序列输出分支。

这比任意双向 cross-attention 更偏向结构。它保留了几何信息的输出路径，但不能数学保证网络真正使用几何：结构特征本身也可能编码家族身份，query/key 也可能退化。需要重新训练的几何对照及未见组评价。偏向结构可能牺牲纯序列基线的性能，不能为保护模态而接受实用性能退化。

## 单一复合物评分与接触读出

使用同一评分器 `S_theta(A,B)` 输出 pKd。对跨伙伴残基对构建对称表示，输入包括 S0、更新后的结构状态、距离基函数；使用向量的扩展版再加入不变的方向信息。接触邻域与距离门控需预先固定，不能按亲和力标签挑选。

同时保留接触表示的未归一化求和、归一化汇总、接触数/界面大小等，再由共享头输出一个分数，减少仅 softmax 平均导致的潜在局部信号稀释。求和特征不能直接命名为物理能量分解；固定几何下，上下文变化也可能影响未突变残基，不宣称严格局部抵消。

WT/mutant 分别完整计算 S，差分只由 `S(mut)-S(WT)` 给出。不能设置一个与绝对评分无关、独自取得好指标的差分预测头。可测试 S(x)-S(x)=0、反对称性和循环差分一致性；这些是代数一致性，不是物理正确性的证明。模型推理只需要待预测复合物的序列/结构，不需要 WT 或实验差分标签。

## 训练阶段与取消固定 0.3

**阶段 A：先训练结构差分能力。** 关闭 ESM 条件通道，以训练集 WT/突变体差分训练结构适配器、结构交互和同一个评分头。PPIformer 原始权重不更新，训练原始实验差分，不拟合某个冻结序列模型的 OOF 残差。此阶段单一任务，不需要绝对/差分损失系数。绝对截距不可由差分确定，留待阶段 B 校准。

阶段 A 的验证要求是差分误差、符号/实验组排序表现相对于常数预测有可重复收益，而非训练拟合或预测方差增大。如果学不出跨组差分能力，应报告失败；不能指望加入 ESM 自动修复它。

**阶段 B：在同一个模型中加入 ESM 条件与绝对监督。** 同时使用 L_abs 和 L_diff，保留结构路径。每个 optimizer update 处理两个任务，分别记录共享结构/attention 模块上的梯度。起步不再加第三项排序 loss，以隔离差分作用。

使用 GradNorm 类动态任务平衡替代固定 lambda_diff=0.3：动态权重由共享层梯度大小及任务学习速度决定，任务权重归一化并保持正值，记录每步有效权重。不能简单让网络最小化 `w * L_diff` 而无约束，否则 w→0 是逃避任务的解。若某任务长期有效梯度接近零，判定任务融合失败，而不是只看总损失下降。

这是取消固定 0.3，不是宣称消除了所有取舍：动态平衡仍有学习率、速度控制参数与抽样安排，必须预先固定或仅由验证集选择。样本中噪声很大的差分也可能被动态算法错误放大，需监测。

先记录 g_abs 与 g_diff 的夹角。只有持续冲突且与验证退化对应时，再将 PCGrad 作为独立对照；不默认叠加所有优化技巧，也不声称梯度投影保证两个任务都改善。

ESM 条件 dropout 采用单向策略：随机去掉序列条件、保留结构通道；同一步 WT/mutant 共用 mask。初始比例可固定为 30%，该比例是模态 dropout 概率，不是差分监督权重。先训练结构、再开放序列，比一开始允许纯序列训练路径更符合本轮保护结构的目标。

## 选模与必要对照

当前目标是未见背景中的 binder/变体排序。新实验的主 checkpoint 按预先确定的验证实验组等权排序选择，平局按差分 MAE；同时报告绝对 MAE/RMSE，并保留绝对最优 checkpoint 作为预先指定的次要结果。必须在运行前固定规则，不从测试指标反选 checkpoint。与旧 RMSE 选模结果比较时明确规则不同。

最小对照在相同划分与可比训练预算下进行：

1. 现有全链 ESM-B：保留为序列参考。
2. 新结构通道，不接 ESM：检验阶段 A 和新共享读出。
3. 新融合结构，仅绝对监督：隔离架构本身的影响。
4. 同一新融合结构，真实差分预热＋联合训练：检验差分迁移。
5. 同一结构，在训练实验组内置换差分标签，保持其边际分布和数据量：区分信息贡献与额外训练/正则化。置换只影响辅助差分目标，不改真实绝对标签；该对照会引入目标冲突，解释时不能当成完美因果实验。

真实差分必须同时超过无差分与置换对照，且跨 seed、同源组成立，才能认定其有效融入。若只优于置换而不优于无差分，不足以证明有益迁移。

结构信息增益需要相同架构重新训练的几何移除/适当破坏对照与独立序列基线。仅在推理时删模态或打乱坐标引起退化，可能只是输入分布突变，不能当作结构贡献的唯一证据。Attention 图和分支梯度同样只是诊断。

输出诊断包括：真实/预测差分分布与标定、零变化基线、实验组宏平均排序、≥5 变体分组、去掉主要贡献同源组、分靶点外部误差、动态任务权重及共享梯度夹角。不得通过强制匹配预测方差或测试集重标定伪造突变敏感度。现有外部16条仅作诊断，新泛化主张需要新的独立数据。

## 一手依据与适用范围

- [DSSA-PPI](https://pmc.ncbi.nlm.nih.gov/articles/PMC12758018/)：使用 PPIformer 结构表示、ESM-2 与分解的跨模态/跨伙伴 attention，支持“保留模态身份再交互”的设计动机。它的 ΔΔG 任务与本文绝对亲和力迁移不同，不能直接借用性能结论。本提案的结构 value 约束与训练阶段是本项目的待验证选择，不宣称为该论文原样方法。
- [GradNorm，ICML 2018](https://proceedings.mlr.press/v80/chen18a.html)：通过梯度幅度和相对学习速度动态平衡任务。它仍有超参数，也不保证噪声大或冲突任务的外推收益。
- [PCGrad，NeurIPS 2020](https://arxiv.org/abs/2001.06782)：处理冲突梯度的候选独立对照，不替代真实任务收益验证。

可以由实现保证的是：原始表示保留、任务梯度路径连通、训练/推理不读取测试标签、差分由同一个评分器产生。不能由架构保证的是：PPIformer 在设计 binder 上准确、ESM 不利用任何捷径、差分监督必然提高未见体系性能。这些必须由上述对照裁决。
