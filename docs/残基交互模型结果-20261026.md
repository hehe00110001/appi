新架构 absolute 相比旧架构 absolute：绝对验证 RMSE 降低约 8.9%，绝对测试降低约 9.2%，差分测试降低约 10.7%。三个种子的绝对/差分测试 RMSE 均低于各自旧模型。这支持本次架构整体升级有作用，但本轮同时改变交互、池化、大小特征和归一化，不能单独归因于其中一项。绝对测试 Pearson 从 0.669 降至 0.628，Spearman 从 0.463 升至 0.554，不能声称所有指标都改善。

## 分组与幅度

差分 test 270 条来自 15 个 PDB 组，其中 1PPF 有 212 条、1A4Y 有 45 条，其余 13 组各 1 条；两大组占 95.2%。绝对 test 401 条来自 70 组，其中 1PPF 有 226 条。总体误差高度受少数组影响。

|---|---:|---:|
| 绝对 test 按组等权 MAE | 1.2550 | 1.2557 |
| 差分 test 按组等权 MAE | 0.9245 | 0.8301 |
| 差分 test 逐条 MAE | 1.3275 | 1.3498 |

| 差分 test 预测标准差 | 0.642 | 0.506 |
| 差分 test 标签标准差 | 1.793 | 1.793 |

联合监督对 8/15 个差分组的三种子平均 MAE 有改善，但两个大组分别恶化约 0.023 和 0.057。按组等权差分 MAE 改善约 10.2%，与逐条指标方向不同，说明收益依赖组，不能概括成所有复合物都变差，也不能从组等权结果推出稳定泛化收益。绝对测试的组等权 MAE 几乎没有改变。

差分恒零参考 test RMSE 为 2.101，恒为训练差分均值的参考为 1.795。新模型两组优于恒零，但三种子平均 RMSE 仍未优于训练均值参考。均值参考不满足一般 WT/mutant 交换时的反对称约束，不是可以直接替代共享打分器的模型，仅用于衡量标签先验。预测幅度仍明显小于标签，平均偏差约 +1 ΔpKd，表明突变效应预测仍不充分。

## 如何理解监督与训练曲线

当前两组都已学习 WT 和 mutant 的绝对端点标签。代码核对了差分标签等于两个端点标签之差，因此额外差分损失没有增加独立实验标签，而是在已有标签上更强调误差之差。令 e_mut、e_wt 为两个绝对误差，差分损失就是 `(e_mut-e_wt)^2`。本实验直接检验的是这项附加约束是否有益，并不等于比较“完全没有突变标签”和“新增独立 ddG 数据”。

训练绝对缩放 MSE 从约 0.54–0.56 降至约 0.015–0.040；验证误差未同步下降，结束时均高于所选最佳值。absolute seed42 的差分训练缩放 MSE 也从 0.655 降到 0.036，说明仅端点监督已能拟合训练差分。现象支持过拟合/跨组泛化限制，而不是仅凭短训练或小模型判断欠拟合；还不能锁定为某一种科学原因。

后续建议先固定本轮架构和当前划分，将新 absolute 保留为对照模型，单独验证联合监督在更广的复合物覆盖上能否重复受益。当前测试集已经多次查看，继续实验宜在预先确定的分组交叉验证或独立留出集上确认；无需删除已有训练条目，也不应根据已观察的测试误差重新选择 λ 或最优 seed。不要把再次加层或扫权重作为默认下一步。
