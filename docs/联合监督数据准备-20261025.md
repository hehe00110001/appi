## 以下记录严格筛查 v1 的方法（诊断与对照用途）

输入：5263 条编码成功的绝对亲和力样本、3603 条 SKEMPI 配对候选。
保留 PPB 发布的 train/val/test 字段，不随机重分。SKEMPI 配对继承所关联绝对样本的 split。

执行：

```bash
python scripts/audit_joint_splits.py
python scripts/prepare_joint_training.py
```

审计同时使用全部 8207 条 PPB 清单中的链序列、已编码记录的实际 WT ATOM 序列、
自有 16 个复合物的所有链（18 条不同序列）。不读取 sgnet5 历史结果。
对完整原始清单审计，避免仅因某条验证/测试记录编码失败就忽略它与训练集的关系。

规则：

- 同 PDB、相同特征路径、完全相同的链序列跨划分时标记冲突。
- BLASTP 2.15.0+ 搜索：E<=1e-3，不使用 SEG，单个 HSP 一致性>=30%，
  覆盖较短链>=80%。任一链满足即标记整个复合物；这是保守的一链筛选，
  不等价于 PPB 作者的 MMseqs 流程，也不代表整个复合物相似。
- 自有数据隔离要求匹配覆盖自有链至少 80%，对所有划分移除命中的记录。
- 冲突优先保留 test，其次 val，最后 train；只过滤较低优先级记录，不改变 split。
- 配对仅在它对应的绝对样本通过同一筛选时保留。

该流程输出第一版冻结编码器基线的保守子集，不替换原始数据；不是完整 PPB 官方测试集，
也不是 CATH-ddG 基准。不能据此宣称完全不存在远程同源或与编码器预训练集的重叠。
原始划分及被过滤记录的原因均保留，未来可报告筛选敏感性分析。

`data/processed/joint_split_audit_v1/` 保存逐行筛选结果、BLAST 命中、序列对应、
相似性证据、输入哈希和外部 PDB 哈希。
`data/processed/joint_training_v1/` 保存 absolute_train/val/test.csv 和 pairs_train/val/test.csv。
导出时再次核对标签配对、特征文件存在性，以及同一 WT/突变体特征不跨划分。
审计表保留 training_eligible=False，导出的通过筛选子集将其设为 True，资格仅限此基线。

训练的差分损失使用 ΔpKd=pKd_mut−pKd_wt，直接由同一实验的两个 Kd 得到，
无需用假定温度换算。kcal/mol 的 ΔΔG 报告保留源数据温度假定标记。
本步尚未启动模型训练；物理标量、排序分组和 CATH-ddG 独立评估不属于此次导出。

验证：8 个 SKEMPI 配对测试和 2 个相似性覆盖率测试通过；最终导出同时执行真实数据一致性断言。
