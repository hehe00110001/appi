## 常数基线与幅度

预测训练 pKd 均值：绝对 test RMSE=1.939，val=1.940。
预测零差分：差分 test RMSE=1.033，val=0.960。
absolute 有绝对预测信号；joint 的绝对 test RMSE 接近训练均值常数基线，
但相关性非零，所以不能说它完全没有信息。
差分 test 预测标准差：absolute 0.096、joint 0.193，而标签标准差为0.935；
差分幅度仍明显收缩，改善有限。不能只凭 Pearson 提升认定突变效应学好。

## 曲线与分布

absolute 最佳 epoch 为4/1/3，停止于29/26/28；joint 为2/1/1，停止于27/26/26。
训练损失持续下降但绝对验证误差上升，joint 后期绝对 val RMSE 达2.59–2.82。
这是过拟合/泛化退化的证据；继续延长 epochs 没有当前证据支持。

训练绝对样本 SKEMPI=3995/4470（89.4%）；验证 PDBbind=325/459（70.8%），
测试 PDBbind=266/330（80.6%）。训练 pKd 均值7.907，验证7.162，测试6.950。
来源组成与标签分布有显著差别。差分监督再次重点约束 SKEMPI，可能增加训练目标与
跨来源绝对预测的冲突；这是合理解释，尚未经因果实验确认。
测试所有四个来源的平均 RMSE 均恶化，非仅单一来源或某个 seed 异常。

## 下一步建议

保留 absolute 作为当前基线，不能把 joint 宣称为更好的整体模型。
先做验证集上的小规模差分权重对照（lambda_diff=0.05/0.1/0.3 vs现有0/1），
其余配置保持一致，先用固定 seed 筛选，再跨种子复核；不按测试表现挑配置。
如小权重仍退化，再单独研究 SKEMPI 体系/来源采样平衡，避免同时改多项而无法归因。
尚未训练排序损失、物理标量或评价自有 binder 排序，因此不能把本轮结果推广到整个方案。
本次只分析结果，没有提交新训练。
