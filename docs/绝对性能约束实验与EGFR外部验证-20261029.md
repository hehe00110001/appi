## 把绝对性能保护变为可检验约束

本轮真实融合在联合第48epoch的绝对验证MAE1.448，而同seed融合绝对基线的最优绝对验证MAE0.9995。动态梯度平衡不自动构成绝对性能约束。

建议区分两个实验层次：

### A. 仅改变checkpoint的可行性规则

冻结同seed、同划分的绝对基线θ0，记录绝对验证MAE `m0`。初始预注册相对容许退化为5%，即阈值`1.05*m0`；这是待验证的工程容忍度，不是统计等效性或实验噪声估计。不能看EGFR或外部16的结果后改阈值。

在满足 `MAE_abs_val(theta) <= 1.05*m0` 的候选里，选择实验组宏平均排序最高者，平局差分MAE最小。θ0自身始终是候选；若没有模型在可行范围内改善排序，则返回θ0，并报告没有实现有益迁移。不能悄悄放宽容忍度或选择一个违约模型。

seed42阈值约1.0495；现有真实差分模型最小绝对验证MAE为1.1075，所以当前整个联合轨迹都不满足这个示例约束。单改checkpoint筛选不会凭空创造可行解，需明确报告不可行。这是使用内部验证数据对后续方案的诊断，不是已证实有效的新模型。

这种规则能保证被选模型在当前验证样本上的MAE限制，不能保证未来测试集MAE限制，也没有改变训练本身。作为selection-only独立对照时，必须标为新规则，不覆写原有主结果。

### B. 真正加入训练约束：以绝对基线为锚点的原始—对偶优化

新建一条实验分支，所有比较臂都从同一个绝对基线θ0开始；保持架构、数据与后续更新预算一致。原来的差分优先预热不再作为这些比较臂不同的初始化因素。这与当前复现实验是不同训练协议，不能声称只改了一个loss系数。

定义共同目标尺度下的训练加权损失，考虑：

`min_theta L_diff_train(theta)`

`s.t. L_abs_train(theta) <= (1 + epsilon_train) * L_abs_train(theta0)`

第一版可预注册`epsilon_train=0.05`，但训练MSE的5%与验证MAE的5%不是等价约束；最终仍需A层验证。

通过拉格朗日形式实现：

`L_model = L_diff_train + lambda * (L_abs_train - b)`

`lambda_next = max(0, lambda + eta_dual * (EMA(L_abs_train) - b))`

其中`b`为冻结基线训练损失允许上限，lambda控制绝对约束的惩罚强度。超过绝对损失预算时自动提高lambda，在可行区域内允许差分继续学习。这里调节的是实际损失违约量，不是让两任务梯度范数相等，也不是把旧固定0.3换个名称。

工程细节需提前固定：lambda初值1，训练归一化沿用同一缓存；先以全训练集计算基线期望损失（ESM开启与关闭两种状态按0.7/0.3加权），避免一个偶然batch决定基线；每步两个任务共用模态mask，EMA衰减0.95；对偶学习率仅可用内部训练/验证选择，首轮可预注册0.01并记录。每个epoch重算完整训练约束是否满足，记录lambda、违约幅度、共享梯度和两任务验证指标。

小批次、Adam、非凸网络意味着该优化不保证每步或最终可行。因此最后只能通过A层checkpoint规则确定可行输出。绝对验证标签不参加反向传播，也不作为每batch的lambda更新信号；EGFR/外部16更不能参与更新。

最小独立对照：同θ0后继续绝对训练；同θ0后GradNorm；同θ0后原始—对偶约束。三者同时应用相同的可行checkpoint规则，再比较差分收益。否则初始化、后续预算和选模规则混在一起，无法归因。当前仅记录方案，尚未提交该分支训练。

### 外部不等于新靶点

在当前训练链上用BLAST做操作性筛查（identity>=30%，query覆盖>=80%，evalue<=1e-3）：

- R2的400条EGFR靶链均命中训练同源序列；R1有结构的187条靶链也命中。
- R1有51条、R2有149条binder链命中训练同源序列。
- 没有完整链精确重复，也没有跨轮binder序列精确重复，但这不能替代同源性分析。
- 按binder identity>=80%、双向覆盖>=80%的连通分量分组：R1=157簇、R2=259簇。报告分类、回归的样本数和家族数，并单独报告binder未命中训练同源筛查的子集。

因此这是**已知/同源靶点上的外部设计binder测试**，不是严格未见靶点测试。若需要“新靶点外推”结论，需独立做排除EGFR及同源训练体系后的模型训练，不能把现在的测试结果直接改名。

论文分析表的`de_novo`二值字段与`design_category`存在明显不一致（例如R1全部为Existing binder，包括33条category=De novo）。本次保留两列，按具体`design_category`分别报告，禁止把整批比赛设计直接称为全de novo数据。

## 预先固定的评估

1. Round2为主；Round1结构来源不同且定量样本少，单独报告。
2. 结合筛选：在明确结合/未检出结合的样本上报告AUROC、average precision（同时报阳性比例基线）、precision@10/20/50。未知/未表达另列，不当作纯结合阴性；这些指标仍是当前实验条件下的测量结果。
3. 连续亲和力：仅在有数值KD且满足上述边界规则的样本上计算MAE/RMSE、Pearson/Spearman；另做包括边界数值的敏感性结果。不把hit预测成功误称为精确亲和力预测成功。
4. 按设计类别、训练binder相似性分层；原始记录携带序列簇/提交者，可用于簇bootstrap和组等权指标。EGFR只有一个靶点，不能用400行掩盖靶点层面的样本量。
5. 现有四组seed42，各两个内部验证选定checkpoint，另列历史全链ESM-B参考；比较原始ipTM、负PAE、pLDDT、ESM PLL的筛选基线，不能给这些无pKd单位的分数计算MAE。
6. 不根据EGFR结果选择checkpoint、设计约束容忍度、重标定pKd或调整测试排除规则。只有完成这一固定外部评估后才能提出新的、需要独立验证的假设。

脚本：`prepare_adaptyv_egfr.py`、`audit_adaptyv_egfr.py`、`extract_adaptyv_egfr.py`、`evaluate_adaptyv_egfr.py`。序列抽取沿用冻结ESM2层33及长链窗口策略，结构编码沿用同一masked-modeling checkpoint、10Å界面裁剪和CPU编码，完全保留训练归一化。
