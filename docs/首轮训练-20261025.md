# 冻结 PPIformer 的首轮预测头训练

默认数据：`data/processed/joint_training_v2`。绝对样本 train/val/test=4470/459/330；
差分配对=3556/32/13。划分与过滤规则见联合监督数据准备说明。

模型输入是已缓存的 768 维对称池化特征，不加载 PPIformer 编码器或重新编码。
共享预测头为 LayerNorm → Linear(768,256) → GELU → Linear(256,1)，输出 pKd。
训练中不使用 dropout，保证同一输入的预测差严格为零；使用 AdamW weight decay。
按绝对训练集的不同特征文件拟合各维均值/标准差，按绝对训练标签拟合目标均值/标准差。
两组使用完全相同的统计来源。均值/标准差作为模型 buffer 保存，不用 val/test 拟合。

模式 absolute：最小化标准化尺度的绝对 pKd MSE。
模式 joint：L_abs + 1.0 L_diff，其中 L_diff 对同一预测头的 S(mut)−S(WT) 与实验 ΔpKd
计算 MSE，并使用相同目标标准差缩放。每个绝对 batch 同时均匀抽样一个差分 batch。
WT 与 mutant 不训练独立模型；ΔpKd 不减目标均值。
本轮不加入物理标量或排序损失，先测量差分监督的独立贡献。

两组分别运行种子 42、43、44。共同超参：batch 64、lr 1e-3、weight decay 1e-4、
最多 200 epochs、25 epochs 无绝对验证 RMSE 改善则停止、梯度范数裁剪 5。
仅按绝对验证 RMSE 选择最佳 checkpoint；测试集只在选模完成后计算。
差分验证指标记录但不参与早停。报告所有固定种子，不能用测试集挑种子。

提交（模型很小，默认 CPU；不需要 GPU）：

```bash
cd /home/weizg/wei/fangyh/appi
sbatch scripts/train_affinity.sbatch
```

Slurm 数组 6 个任务，同时运行最多 2 个；每个任务 2 CPU、8 GB、4 小时时限。
默认使用集群默认分区。任务 0/1 是 seed42 的 absolute/joint，2/3 是 seed43，4/5 是 seed44。
日志 `logs/train-<array job id>_<task id>.log`。
输出 `runs/affinity_v1/{absolute,joint}_seed{42,43,44}/`。

每轮保存 last.pt（模型、优化器、随机状态、epoch）、验证改善时保存 best.pt。
自动恢复已有 last.pt；参数或数据/代码/特征指纹变化则拒绝复用旧目录。
续跑保持原 epochs 等参数；更换实验参数应使用新输出目录。
目录文件锁避免同一运行同时写入。checkpoint 原子替换，epoch 日志按轮次保存。
metrics.json 表示完成，包含选中 epoch、val/test 的 RMSE、MAE、Pearson、Spearman；
predictions_*.csv 保留原始行号、标签和预测。绝对单位 pKd、差分单位 ΔpKd。
假定温度不参与差分训练。不要把仅 13 条差分测试记录的指标当作主要 ΔΔG 基准结论。

全部任务结束后：

```bash
python scripts/summarize_training.py
```

所有 6 组完成时写入 `runs/affinity_v1/comparison.json`，汇总固定种子的均值和样本标准差。
不足 6 组会列出缺失文件，绝不混入带 --limit 的 smoke 输出。
