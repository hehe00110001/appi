# APPI seed44：研究预发布候选

版本：`v0.1.0-rc1-seed44`。状态：本地发布包已准备；GitHub 推送和 Release 上传由用户手动执行。

## 模型身份与选择

- 训练运行：`fusion_transfer_seed44`；主 checkpoint：`joint/best.pt`；联合阶段第 **16** 轮。
- 轮次按内部验证实验组宏平均排序选择，平局按差分 MAE；不是绝对 MAE 最优的次 checkpoint。
- **seed44 是用户在查看内部测试和 EGFR 外部结果后指定的发布候选。** 因此它不是事先选定的无偏外部验证结果；三 seed 完整对照须同时引用，不能仅以该 seed 宣称稳定泛化突破。
- 可训练参数：554,183。编码器冻结。发布包只包含训练后的评分网络与归一化 buffer，不重新分发 PPIformer / ESM 编码器权重。

## 输入、架构与输出

输入为双伙伴复合物的界面 PPIformer 128维残基特征、坐标、伙伴标记，以及 ESM-2 `esm2_t33_650M_UR50D` 第33层的全链1280维特征和精确节点映射。

结构隐藏维128，序列上下文64维，2层、4头注意力。ESM 上下文影响结构消息的注意力权重；结构消息的 value 来自结构状态。原始 PPIformer 特征另有保留到读出的通道。结构接触读出阈值16Å。此架构约束不等同于已证明模型只利用界面物理。

输出为 `predicted_pkd`，定义为 `-log10(Kd / M)`，数值越大表示模型预测结合越强；不是结合概率。当前外部绝对校准不足，不应把输出直接视为可信实验 Kd。

## 训练和监督

数据使用项目 `joint_training_complex40_v1` 固定划分：绝对训练/验证/测试4471/394/394；差分3061/269/271。来源与划分细节见仓库文档和结果快照；40%复合物序列分组不等同于每侧蛋白均严格独立。

30轮结构差分预热，随后100轮联合训练；发布的是联合第16轮模型。两个端点共享评分函数，差分定义为 `S(mutant)-S(WT)` 的实验 ΔpKd，采用 GradNorm 平衡绝对与差分任务。实验差分属于监督信号，不是自监督。

`modality_dropout=0.3` 是训练时关闭序列上下文的概率，推理时关闭该随机丢弃；它不是固定的差分 loss 权重。`rank_deadband=0.3 pKd` 是排序评估的标签间隔规则，含义也不同。

seed44 EGFR AUROC 的序列簇bootstrap95%区间为[0.591,0.747]，定量Pearson为[-0.034,0.452]。EGFR靶链与训练链同源，不代表未见靶点泛化。

真实融合 seed42/43/44 的 EGFR AUROC 为0.486/0.575/0.672；定量Pearson为0.110/-0.011/0.231；三seed平均AUROC0.577±0.093。纯结构、无差分及置换对照均保留在Git结果快照中。

探索性100nM阈值下，seed44前20没有已确认高亲和力命中，另有1条亲和力待核查；仅在44条定量记录内排前10时命中1条≤100nM。不能宣称已验证高亲和binder筛选优势。100nM阈值系既往结果查看后提出，属于探索性分析。

适用于研究复现、候选评分对照和后续微调起点。尚不支持可靠的通用绝对Kd预测、稳定的未见靶点外推，或免实验验证的高亲和力筛选。

发布包包含 `model.pt`（纯state_dict，含训练归一化）、`config.json`、`manifest.json`、模型/数据加载源码、`scripts/predict_release.py` 和推理说明。原始训练checkpoint与发布文件分别记录SHA256。优化器状态和训练缓存不随包发布。

当前推理接口接受已按本项目流程生成的缓存；不是任意PDB/FASTA一键预测服务。第三方编码器及原始数据需按各自来源获取与遵守其使用条款。本次没有为第三方资产新增或改变许可证，也没有为仓库擅自指定新的开源许可证。
